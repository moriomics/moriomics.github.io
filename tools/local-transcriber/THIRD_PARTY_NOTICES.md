# Third-party components

Local Transcriber integrates independently maintained components including Python, PySide6 / Qt, faster-whisper, CTranslate2, PyAV, FFmpeg / ffprobe, ONNX Runtime, Hugging Face Hub, tokenizers, python-docx, keyring, the OpenAI Python SDK, and PyInstaller.

This source publication does not vendor their source distributions, executable binaries, runtime DLLs, or model weights. The dependency files identify the versions used by the application configuration; each upstream project retains its own licenses, notices, and terms.

- Python: https://www.python.org/
- Qt for Python: https://doc.qt.io/qtforpython-6/
- faster-whisper: https://github.com/SYSTRAN/faster-whisper
- CTranslate2: https://github.com/OpenNMT/CTranslate2
- PyAV: https://github.com/PyAV-Org/PyAV
